# Agent Design Skill

## 工作流程

1. 理解需求。
2. 明确系统边界。
3. 分析现有架构。
4. 对照项目 Architecture。
5. 提出设计方案。
6. 分析方案优缺点。
7. 输出 详细的执行Plan（技术+业务)。
8. 等待用户确认。
9. 才能开始编码。

## 特殊要求

如果大模型认为现有架构存在问题：

- 必须指出问题。
- 必须说明原因。
- 必须提出替代方案。
- 不允许未经确认改变核心架构。
